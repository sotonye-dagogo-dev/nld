# DESIGN.md Convention (skill reference)

> **Metadata**
> - last-updated-by: v3 upgrade (skill authoring)
> - last-verified-against-code: (set on first use)
> - staleness-policy: Tier 4 reference — re-verify before relying on anything in a specific audit

The `DESIGN.md` convention (adopted from a curated `DESIGN.md` collection — see `tools/registry.md` for the source) is:

- One plain-markdown doc per reference site, indexed by source and date pulled.
- Sibling to the project's own docs, never merged into `design-system.md`.
- Contains: palette with usage, type scale, spacing, component patterns, and the one-line verdict of which tokens are worth promoting.

See `design-references/README.md` for the folder contract and `design-references/TEMPLATE/DESIGN.md` for the blank shape.
