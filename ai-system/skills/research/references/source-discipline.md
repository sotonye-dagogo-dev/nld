# Source discipline (skill reference)

> **Metadata**
> - last-updated-by: v3 upgrade (skill authoring)
> - last-verified-against-code: (set on first use)
> - staleness-policy: Tier 4 reference — re-verify before relying on anything in a specific audit

The rules that made the v3 audit reliable — reuse them verbatim:

- Registry first: check `tools/registry.md` before re-researching a subject already evaluated.
- Primary over secondary: vendor repo / official docs / the standard's own text first.
- Anchor the claim: "source says X" vs. "I infer Y from X." Never present inference as fact.
- Mark confidence: unverified vendor claims get an explicit "unverified claim" tag.
- Inaccessible = needs-human-input: say exactly what is missing (content, screenshot, working link). Guessing what a blocked page says is the one sin that corrupts every downstream decision.
