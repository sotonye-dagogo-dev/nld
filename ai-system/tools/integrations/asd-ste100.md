> **Overview:** Aviation's Simplified Technical English standard adopted as a documentation style rule: short sentences, one action per verb, one meaning per word. No repo — it is a standard, not a tool. Recorded here so the provenance of the style addendum to engineering principles §9 is traceable.

---

## What it is

- ASD-STE100: 53 rules, ~900 approved words, one meaning per word, one verb per action. Designed so manuals are unambiguous for non-native readers.
- Applied in v3 for a second reason: plain single-meaning-word style makes agent-authored docs cheap to re-read every session and free of the padded phrasing that marks AI-written prose.

## How an agent uses it

- Write all `ai-system` docs and generated documentation in this style (per the style addendum to §8 of the v3 plan).
